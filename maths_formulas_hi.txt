गणित के महत्वपूर्ण सूत्र (JEE)

द्विघात समीकरण

ax^2 + bx + c = 0 के मूल x = (-b +/- sqrt(b^2 - 4ac)) / (2a) होते हैं। विविक्तकर D = b^2 - 4ac। यदि D > 0 हो तो मूल वास्तविक और भिन्न होते हैं, D = 0 पर मूल वास्तविक और बराबर, और D < 0 पर मूल सम्मिश्र होते हैं। मूलों का योग = -b/a और गुणनफल = c/a।

समान्तर श्रेढ़ी

n वाँ पद = a + (n-1)d और n पदों का योग = (n/2)(2a + (n-1)d)।

त्रिकोणमिति

sin^2(x) + cos^2(x) = 1। sin(2x) = 2 sin(x) cos(x)।

अवकलन

d/dx (x^n) = n x^(n-1)। d/dx (sin x) = cos x। d/dx (e^x) = e^x।

सारणिक

2x2 आव्यूह [[a, b], [c, d]] का सारणिक ad - bc होता है। आव्यूह तभी व्युत्क्रमणीय होता है जब उसका सारणिक शून्य न हो।
